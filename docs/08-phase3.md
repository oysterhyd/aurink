## 1. 目标

Phase 3 结束时（M3）得到 Beta：02 标 P1 的功能全部可用，观感对齐全部 18 张基线。

1. **公式和 Mermaid：** 实时模式里显示渲染结果。光标进入时显示源码和下方的实时预览。渲染服务不可用时显示源码，内容不丢。
2. **扩展语法：** Front Matter 编辑式页眉、`[TOC]`、`==高亮==`、`^上标^`、`~下标~`、`:emoji:`、`[[Wiki 链接]]`，每项可以在设置里关闭。关闭时解析结果和 GFM 完全一致。
3. **视图模式：** 阅读、专注、打字机三种模式。内容宽度、字号、行高可调，窗口可缩放。
4. **写作交互：** 斜杠菜单、选区格式条、图片灯箱、平滑光标。
5. **设置和导出：** 设置界面覆盖全部 `Settings` 字段并实时生效。可以导出 PDF 和打印，导出时有进度通知。中文、英文两种界面都完整。
6. **动效：** 02 §4.4 的运动规则逐条走查。欢迎页有极光，切换主题时径向溶解，正文滚动时出现联动标题，切换文档时显示骨架屏。减少动态效果、减少透明度两种设置下行为都合规，空闲时 0 帧。

Phase 4 再做：大文档、HTML 块安全渲染、自定义主题和键位、旧编码、发布签名、macOS 和 Linux 真机验收。

## 5. 设计决定

负责人在批次 1 落实。这些是任务卡没写清、Codex 不该自己决定的地方。

| # | 问题 | 决定 |
|---|---|---|
| D1 | MyGo 的解析器只认公式（`$$`、`\[ \]`，以及 `parser.ExtDollarMath` 打开后的 `$`），没有高亮、上下标、emoji、Wiki 链接、TOC [源码 `ui/markdown/parser`] | 在 `core/markdown` 适配层对解析结果做一遍后处理：只看 `InlineText` 节点，跳过代码、转义、自动链接和 HTML。`ExtDollarMath` 直接传给解析器。`[TOC]` 在叶子段落这一层识别。markdown.go:405–410 的 6 个 `TODO(BE-1.7)` 是入口 |
| D2 | 关掉扩展时必须和 GFM 完全一致 | 每个扩展单独开关都跑一次语料：关闭时 AST 和不加后处理的结果逐节点相等，开启时只有扩展节点不同。增量解析（BE-1.2）和全量解析的结果仍要相等 |
| D3 | `~` 和 GFM 删除线冲突 | `ExtTildeSub` 默认开启（U1）。开启时单个 `~` 是下标，`~~` 仍是删除线；关闭时单个 `~` 按 GFM 是删除线 |
| D4 | emoji 短码表 | 用 gemoji（MIT）的数据生成 Go 表，放在 `core/markdown`，许可证随附。不认识的短码保持原文。不加依赖，只放数据文件 |
| D5 | YAML Front Matter 的解析 | 不加 YAML 依赖，`core/markdown` 解析一个子集：顶层的 `key: 标量`、`key: [a, b]`，以及块列表 `- a`。页眉用三个字段：`title` 或 `kicker` 作 kicker，`tags` 或 `keywords` 作标签，`date` 作日期。解析不了时显示淡色源码（就是现在的表现） |
| D6 | Wiki 链接的目标 | 依次找：同目录的 `目标.md`，工作区索引（`app/index.go`）里同名的文件，`目标#标题` 定位到标题。找不到时，链接显示为未解析的样式，点击发一条通知，不自动新建文件 |
| D7 | 渲染资源 | 照搬 S2 的 MathJax 3.2.2 和 Mermaid 10.9.3，SHA-256 见 S2 报告，许可证文件随附，放在 `resources/render`，用 `go:embed` 打包，二进制大约多 5.2 MiB。页面的 CSP 禁止一切网络请求。用非空的虚拟基址加载，避开 `NavigateToString` 的 2 MiB 上限（S2 实测） |
| D8 | 渲染宿主的生命周期 | 主窗口建一个 `NewWebView`，从不挂载到界面上（S2 的做法），用 `ThrottlingOff`。第一次有渲染请求时才启动，空闲 60 s 后关闭，下次请求再启动。请求串行处理，每个请求限时 2 s。块离开视口或被编辑后，取消还没开始的请求。渲染进程退出时，正在处理和排队的请求返回 `CodeUnavailable`，下一个请求重新启动页面；启动本身失败时，1 分钟内的请求直接返回 `CodeUnavailable`，不再尝试 |
| D9 | 输出格式 | 公式输出不含 `<text>` 时用 SVG，含 `<text>` 时用 PNG（ADR-002、CR-005）。Mermaid 一律用 PNG，像素是 DIP 乘以屏幕缩放。行内公式要返回 `Ascent` |
| D10 | 缓存 | 键是 kind、源码、Dark、字号、颜色、缩放、资源版本的 SHA-256。内存 LRU 上限 256 条或 32 MB。磁盘缓存放在 `PathCache/render/`，上限 64 MB，按修改时间淘汰。05 要求命中 < 1 ms |
| D11 | 主题切换 | 颜色在缓存键里。切换后先继续显示旧结果，新结果到了再换，不闪成源码 |
| D12 | 实时模式里的交互（02 §5.9） | 光标不在里面时显示渲染结果。光标进入后显示等宽源码，下方是预览，停止输入 150 ms 后更新。渲染失败时红色细边框加错误文本。服务不可用时显示源码，同一会话只通知一次。渲染永远不在击键路径上同步执行 |
| D13 | 异步结果改变块的高度 | 走现有的滚动锚点：视口顶部的块不动。有缓存时直接用缓存的尺寸，没有时按源码行数估一个高度 |
| D14 | PDF | BE-2.10 用 BE-2.8 的导出结果，把公式和图表以 data URI 嵌入，再交给 `Printer.HTMLToPDF`。`Printer` 由 app 用 MyGo 的 `Page.PrintToPDF` 实现 [源码 `pdf.go`]，另开一个隐藏页面，不占渲染服务。中文界面默认 A4，英文界面默认 Letter。打印走 `Page.Print()`，行为 [待验证] |
| D15 | 设置实时生效 | 每个字段都有一个场景测试：改完不重启就生效。语言用 `App.SetLocale` 切换 [源码 `locale.go`]，伪本地化用 MyGo i18n 的 en-XA 测试截断 |
| D16 | 强调色 | `theme` 根据 `AccentHue` 计算强调色系列，4 个预设。实现前先核对 `theme.For` 现在是不是写死了色值 [待验证] |
| D17 | 阅读模式 | 是窗口的视图状态，不是文件只读：不改 `Session` 的只读状态。退出后每个标签回到进入前的模式（源码标签读的时候用实时视图，退出回源码）。滚动位置留在读到的地方，不跳回进入时的位置（批次 4 修订：读完往下翻了，退出时跳回去反而丢了位置）。阅读时切到别的标签，那个标签也进入阅读；关掉最后一个标签就退出阅读；选择实时或源码视图会先退出阅读 |
| D18 | 动效 | `ReduceMotion`（跟随系统、开、关）关掉一切位移和缩放动画，只保留不超过 150 ms 的淡入淡出。`ReduceTransparency` 走 02 §6 的低功耗路径。极光 12 s 后停止请求帧 |
| D19 | 大文件模式 | 文档进入大文件模式时，渲染服务不启动，公式显示源码 |

契约改动按 05 §4 在同一次提交里同步实现、`contracttest` 和 04 文档。

## 6. 任务要点

### 批次 2：BE-1.7 扩展语法（Codex）

- 按 D1–D6。每个扩展开、关两种模式都要有黄金测试（05）。
- 编辑命令：高亮、上标、下标的切换（作用于选区，规则和现有的加粗、斜体命令一致），插入 TOC，插入 Wiki 链接。
- 投影：高亮、上下标、emoji、Wiki 链接、TOC、Front Matter 的显示规则。光标进入时显示标记，和现有的行内节点一致（04 §4.3）。
- 关闭扩展后，语料保真和 1 万步属性测试仍要通过。

### 批次 2：BE-2.9 渲染服务（Codex）

- 按 D7–D11。`core/render` 不能导入 mygo，宿主放在 `adapters/webviewhost`，通过窄接口注入（07 D1 的做法）。
- 05 的标准：公式语料 ≥ 200 例，每例的 SVG 都能被 `ui.ParseSVG` 解析，或者走 PNG 并且有墨迹。Mermaid 6 种图。缓存命中 < 1 ms。
- 补上 ADR-002 留下的待验证项：PNG 路径端到端的耗时、2× 缩放、基线对齐、空闲退出后重启的耗时、退出能回收多少内存。不达标时退回只显示源码（ADR-002），并写进报告。
- 测试用替身宿主，断言请求次数和顺序，不按墙钟等待。真实 WebView 的测量放在一个单独的工具里，结果写入 `reports/quality.md`。

### 批次 3：BE-2.10 PDF（Codex）

- 05 的标准：CJK、代码块、公式、图片在 PDF 里都正确。负责人把生成的 PDF 逐页转成图片看一遍，不只检查文件能不能打开。
- 支持取消和 `OnProgress`。

### 批次 4、7：FE-1.7 模式与交互

- 专注模式的淡化、打字机模式的居中都只改绘制，不改排版，不触发全文档重排（用 Stats 计数断言）。
- 斜杠菜单：只在空段落行首输入 `/` 时弹出。`Esc` 关闭并保留 `/`。IME 组字时不弹。
- 格式条：选区为空、正在 IME 组字、源码模式时都不出现。“转换”菜单走现有的块命令。
- 灯箱：`Esc` 飞回原位，缩放 60–160%，`ReduceMotion` 下没有飞行动画。
- 每个基线都要在 `ReduceMotion` 下验证没有位移动画（05）。

### 批次 5：FE-2.7 设置

- 820×580 Modal，5 个分类：外观、编辑器、文件、扩展语法、快捷键（只能查看）。
- 中英文文案的键加在允许的前缀下，`mygo i18n check` 通过。切换语言不重启，界面文字没有截断。

### 批次 6：FE-1.6 富组件

- 公式和图表加载时有骨架扫光，然后淡入（02 §5.9）。图表多个时依次淡入。

- Front Matter 页眉对照 `Main` 基线。

### 批次 8：FE-2.6 动效与特效

- 把 02 §4.4 的每一条规则列成表，每条写清证据（Tester 断言、录屏或截图），结果写入 `reports/parity/Motion.md`。
- 空闲 0 帧（`FramePending`）：欢迎页极光开始 12 s 后为 0，其余界面一直为 0。

### 批次 9：INT-3.1

- 安装包：在本机实际安装、卸载、重装，双击 `.md` 打开。图标用设计稿里的图标。

### 批次 10：QA-3.x
