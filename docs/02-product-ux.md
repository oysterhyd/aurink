# 02 · 产品功能与 UI/UX 规范

> 视觉与交互基线：**Ink & Aurora**。本文 §3–§7 与 [`design/`](design/README.md) 中的可运行原型、基线截图共同构成验收依据；三者不一致时提 CR，由 CEO 裁决，不得自行取舍。

## 1. 产品定位

**Aurink**：轻量、即开即写、所见即所得的跨平台 Markdown 编辑器/阅读器。
- 对标 Typora 的功能面：实时渲染、源码模式、文件树、大纲、导出、数学、图表。
- 体验参照 Linear（精确、键盘优先、克制的暗色）、Raycast（命令面板、速度感、玻璃材质）、Craft（文档排版、留白、卡片感）；风格为 Editorial Minimalism + Soft Glass + Motion UI。
- 品牌概念：墨滴是不变的源码，极光是光标经过时的表现。标语「Markdown 文件就是你的文件。」
- 核心承诺：**Markdown 文件就是你的文件**——打开、编辑、保存不改动你没碰过的任何一个字节。

设计原则：
1. 内容优先：编辑区之外的一切默认安静，需要时出现。
2. 键盘即一切：所有功能可通过命令面板与快捷键到达。
3. 动效服务于理解：动画用于说明"东西从哪来、到哪去"，时长短、可被打断、遵循系统"减少动态效果"；空闲时 0 帧。
4. 无损与可信：保存状态、外部修改、冲突永远可见、可恢复。

### 4.4 动效令牌（`internal/views/motion`）
| 令牌 | 定义 | 用途 |
|---|---|---|
| `Quick` | 曲线 120 ms EaseOut | 悬停颜色、标记淡入淡出 |
| `Snappy` | Spring 260 ms, bounce 0.15 | 按钮、胶囊、小浮层、按压回弹 |
| `Smooth` | Spring 360 ms, bounce 0 | 布局变化、侧栏、滚动、选中药丸 |
| `Gentle` | Spring 520 ms, bounce 0.1 | 大面板、Shared Element 飞行 |
| `Stagger` | 每项 +24 ms，上限 8 项 | 列表/面板逐项进入 |

运动规则（全部为验收项，演示见 `design/baseline/Motion.png` 与可运行的 `Motion.dc.html`）：
1. **一源一终**：浮层从触发点长出，并回到触发点。
2. **一个选中药丸**：标签、分段控件、菜单、面板的选中态都是同一个滑动药丸，不是逐行变色。
3. **文字不弹**：标记只淡入淡出，宽度立即变化，避免文字抖动。
4. **空闲 0 帧**：循环动画必须有终点；极光 12 s 后停止。
5. **减少动态效果**：取消位移与缩放，保留颜色与淡入。
6. 所有动画可打断（Spring 保持速度）；优先 `AnimatePose`/`ContentTransition`，避免每帧重建大视图。
7. 微交互：悬停 `hoverTint`；按压 scale 0.965 后 `Snappy` 回弹；光标闪烁带微弱辉光。

## 5. 关键交互规范

### 5.1 光标处显隐（Reveal）
- 默认 **内联级**：光标位于某内联节点内部或紧邻其边界时，该节点及其祖先节点的标记以 `textMuted` 显示（`Quick` 淡入，宽度变化不做动画）；离开后隐藏。
- 标题 `#`：不进入内容列，块类型由页边标签表示；光标在行首时才显示 `#`（淡色）。
- 代码块围栏、数学块 `$$`、Front Matter `---`：光标进入块时显示（Collapse 展开）。
- 列表符号、引用 `>`：始终渲染为装饰；行首 Backspace 执行"降级/移除列表"命令。
- 块标记后跟空格才生效（对齐 Typora）：单独的 `#`、`+`、`-`、`*`、`1.`、`>` 在其后输入空格之前按普通文本显示，不隐藏、不换成装饰（2026-11-02 用户裁定）。
- 选区跨越节点时：选区内节点全部显示标记。
- 设置项：`显隐粒度 = 内联 | 块 | 始终显示源码标记`。

### 5.2 软换行
- 默认 `换行显示`：段落内单个换行显示为换行；可选 `空格显示`（CommonMark 语义）。

### 5.3 斜杠菜单（P1，`Slash.png`）
- 500×316 双栏玻璃面板（Panel），从光标处长出（`Snappy`）。左栏分组列表 + 滑动药丸，右栏预览（说明 + 语法）。
- 15 项：**基础** 标题 1–3、无序/有序/任务列表、引用；**媒体与结构** 代码块（下一步选语言）、表格（下一步选尺寸）、图片、分隔线、目录、脚注；**高级** 数学块、Mermaid。
- 键入过滤；↑↓ 选择，Enter 插入，Esc 关闭并保留 `/`。

### 5.4 命令面板 / 快速打开（`Palette.png`）
- `Ctrl+P` 文件模式；`Ctrl+Shift+P` 命令模式（`>`）；`@` 跳转标题。模式徽标 文件/命令/标题。
- 宽 640、距顶 86，Modal 材质，遮罩 `scrim`；从 omnibox 以 `Gentle` 长出（`ElementTransition.Match`），退出 130 ms 回到 omnibox；打开时一次性锥形辉光边框扫过 1.5 s（GPU 且未开减少动态效果时）。
- 输入区高 56；行高 40：图标、标题（匹配字符高亮）、右侧快捷键胶囊；分组标题；滑动药丸。页脚「↑↓ 选择 · Enter 执行 · Esc 关闭」+ 条数。
- 打开文件时，选中行飞入标签条（`Gentle`）。

### 5.5 保存状态（胶囊）
- 已编辑（空心点）→ 保存中（`accent` 脉动）→ 绘制对勾「已保存」，1.5 s 后淡回圆点。冲突时显示「有冲突，未写入」。

### 5.5.1 冲突横幅（`Conflict.png`）
- 玻璃内联条「文件已被其他程序修改」：`保留我的版本` / `载入磁盘版本` / `对比`（P2）。

### 5.6 文件树
- 展开/折叠：箭头旋转，子项 FLIP 展开。
- 拖拽移动：行上浮（`Pose{Scale:1.02, Y:-2}`），目标文件夹高亮；落下后 `Smooth` 归位并出现带「撤销」的通知。
- 行内重命名：F2 / 双击；同名时即时提示「已存在同名文件」。右键菜单；未保存圆点。

### 5.7 大纲
- 当前标题指示条滑动（scroll spy）。点击 `ScrollTo(…, Smooth)`，到达后目标标题背景闪烁一次。

### 5.8 表格
- 圆角容器；活动时上方出现玻璃工具条（+行 / +列 / 格式化表格），活动单元格带环；右键菜单含插入、删除、对齐。
- Tab / Shift+Tab 跨单元格；最后单元格 Tab 新增一行；`Ctrl+Enter` 下方插入行。

### 5.9 数学与 Mermaid（P1）
- 首次渲染：骨架扫光 +「正在启动公式渲染 / 正在渲染图表」，完成后淡入（图表逐项 stagger）。
- 未激活：渲染结果。激活：源码面板（等宽）+ 下方实时预览；失败时红色细边 + 错误文本。不可用：显示源码 + 通知。

### 5.10 模式切换
- 源码模式（`Source.png`）：内容交叉淡化，保持光标行相对位置；行号栏、活动行、内联 Token 着色。
- 阅读模式（`Reading.png`）：标题栏、页边标签淡出，侧栏收起，纸张铺满窗口且圆角归 0；顶部 2 DIP 极光进度条（带辉光）；滚过 H1 后文档标题在顶部居中淡入；右上角「退出阅读」。`F7` / `Esc`。
- 专注模式（`Focus.png`）：非当前块不透明度 0.28，上下渐隐遮罩，侧栏自动收起，标题栏不透明度 0.55。
- 打字机模式：光标行保持在视口 45%，带淡色光带。

### 5.11 选区格式条（P1，`Format.png`）
- 高 40 的 Chip 玻璃条，选区上方 `Snappy` 出现。「转换」菜单（正文/标题 1/标题 2/引用）+ B I U S `<>` 链接 高亮，当前格式有激活态。点链接就地变形为地址输入框。

### 5.12 图片灯箱（P1，`Lightbox.png`）
- 从图片 FLIP 飞入（`Gentle`），背景 `scrimStrong` 加模糊；底部玻璃药丸 − / 百分比 / + / 适应 / 关闭；Spring 缩放 60–160%；Esc 飞回原位。

### 5.13 通知（`Notify.png`）
- 底部居中玻璃栈，最多 4 条：图标、标题、说明、可选动作（撤销/打开/重试）、关闭、可选进度条（导出）。Spring 进入，移除时其余项 FLIP 补位。动作型错误不自动消失。

### 5.14 查找（`Find.png`）
- 右上角 440 宽 Panel 玻璃：选项 Aa / W / .*、计数、替换行 Collapse；命中同步到结构导轨。

### 5.15 设置（`Settings.png`）
- 820×580 Modal；分类滑动药丸：外观/编辑器/文件/扩展语法/快捷键。主题卡片、强调色色块、字体/字号/行高/宽度实时生效、显隐粒度、软换行；开关旋钮 Spring。

### 5.16 其他反馈
- 切换文档：文档骨架 + 扫光约 280 ms（`Loading.png`）；≤ 100 ms 完成的切换不显示。
- 主题切换：从点击点径向溶解 400 ms。
- 任务项：复选框 Spring + 绘制对勾，完成项删除线。脚注悬停弹层；链接弹层（`编辑 Ctrl+K` / `打开`）。

## 6. 材质与 Shader 使用规范

| 位置 | GPU 路径（MyGo 实现） | 低功耗路径（CPU 或减少透明度） |
|---|---|---|
| 窗口底（标题栏 + 侧栏） | 窗口 Vibrancy（Win11 Mica/Acrylic，macOS）；视图根透明处叠极光色调 | `window` 低功耗实色 |
| 滚动联动标题、纸张顶边 | `glass.ScrollEdge{Soft}` | 实色 + 发丝线 |
| Chip / Panel / Modal | `glass.Glass{Regular}`（调 `Tint`、`Clarity` 逼近 §4.3），按钮 `Interactive: true` | §4.3 实色填充 + 阴影 |
| 灯箱控件 | `glass.Glass{Clear}` | 半透明黑 60% |
| 灯箱背景 | `glass.Blur` + `scrimStrong` | 仅 `scrimStrong` |
| 欢迎页/空文档极光 | `ui/shader` Fragment（低频噪声 + 极光三色），12 s 后停止请求帧 | 静态渐变 |
| 命令面板辉光边框 | `BorderConicGradient` 一次性动画 1.5 s | 无 |
| 主题切换 | LayerEffect 径向溶解 400 ms | 交叉淡化 |
| 加载占位 | 线性渐变扫光 | 静态 |

硬性约束：Shader 仅用于装饰，不承载信息，只在欢迎页、空文档和上述一次性效果中使用；全部 `p.Accelerated()` 门控；常驻视图不得有持续请求帧的动画。原型中的玻璃和动画是浏览器模拟，模糊值是视觉目标；Native 上的外观与帧率由 S4 确认 [待验证]。

## 8. 无障碍与国际化
- 编辑器角色为多行文本框，带标签；所有命令可键盘到达；焦点环可见；`TextScale`、高对比、减少动态效果、减少透明度均遵循。
- 已知限制：读屏软件读取全文能力弱于系统文本控件（自定义编辑器只向辅助技术暴露活动区域）。
- 界面语言：简体中文、英文（P1）；文案键按模块分片（见 05 文档 §3.4）。
