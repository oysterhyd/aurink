# 02 · 产品功能与 UI/UX 规范

## 1. 产品定位

**Aurink**：轻量、即开即写、所见即所得的跨平台 Markdown 编辑器/阅读器。
- 对标 Typora 的功能面：实时渲染、源码模式、文件树、大纲、导出、数学、图表。
- 体验参照 Linear（精确、键盘优先、克制的暗色）、Raycast（命令面板、速度感、玻璃材质）、Craft（文档排版、留白、卡片感）。
- 核心承诺：**Markdown 文件就是你的文件**——打开、编辑、保存不改动你没碰过的任何一个字节。

设计原则：
1. 内容优先：编辑区之外的一切默认安静，需要时出现。
2. 键盘即一切：所有功能可通过命令面板与快捷键到达。
3. 动效服务于理解：动画用于说明"东西从哪来、到哪去"，时长短、可被打断、遵循系统"减少动态效果"。
4. 无损与可信：保存状态、外部修改、冲突永远可见、可恢复。

## 3. 信息架构与布局

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ ●●●  ▸ 侧栏   │ 标签: README.md ×  │ 笔记.md •  │ +          ⌕  ⌘K  ◐       │  ← 自绘标题栏（DragWindow），玻璃/Mica
├──────────────┬───────────────────────────────────────────────────────────────┤
│ [文件|大纲|搜索]│                                                               │
│              │              ┄┄┄┄ ScrollEdge 软渐隐 ┄┄┄┄                         │
│ ▾ docs       │        # 标题                                                  │
│   README.md  │                                                               │
│   笔记.md     │        正文以 720 宽居中，行高 1.75，段距 0.75em……              │
│ ▸ assets     │                                                               │
│              │        ```go                         [go] [复制]               │
│ (Vibrancy /  │        func main() {}                                         │
│  Surface)    │        ```                                                    │
│              │                                                               │
│              │                                      ╭─────────────────────╮  │
│              │                                      │ ● 已保存 · 1,284 字 │  │ ← 玻璃状态胶囊
│              │                                      ╰─────────────────────╯  │
└──────────────┴───────────────────────────────────────────────────────────────┘
```

- 侧栏：默认 248 DIP，可拖动（`ui.Split`，160–420），`Ctrl/⌘+Shift+L` 折叠（宽度 Spring 过渡）。顶部三段分段控件：文件 / 大纲 / 搜索。
- 标签栏位于标题栏行内（Linear/Arc 风格），未保存标记为圆点，悬停变为关闭按钮（ContentTransition 图标切换）。
- 编辑画布：内容列居中，最大宽度 720（设置 600–960），顶部留白 72，底部可滚过末尾半屏。
- 状态胶囊：右下角浮动玻璃胶囊，显示保存状态、字数、阅读时长、光标位置；悬停展开详情。
- 横幅区：冲突/外部删除/只读/大文件提示以内联横幅出现在编辑区顶部（Collapse 进入）。
- 空状态/欢迎页：最近文件列表 + 极淡的极光 Shader 背景（仅 GPU、空闲时静止）。

## 4. 设计系统（Design Tokens）

所有令牌由 `internal/views/theme` 定义，组件只引用令牌，不写字面值。

### 4.1 颜色
| 令牌 | Light「Daylight」 | Dark「Midnight」 | 用途 |
|---|---|---|---|
| `bg` | `#FFFFFF` | `#0B0B0F` | 编辑画布 |
| `chrome` | `#F7F7F9` | `#0F0F14` | 标题栏/侧栏（无 Vibrancy 时） |
| `surface` | `#F2F2F5` | `#16161D` | 卡片、代码块、输入框 |
| `surfaceHover` | `#EAEAEE` | `#1E1E27` | 悬停 |
| `border` | `#E3E3E8` | `#262630` | 分隔线、描边 |
| `text` | `#18181B` | `#EDEDF1` | 正文 |
| `textMuted` | `#6B6B76` | `#9B9BA8` | 次要文本、标记显示 |
| `textFaint` | `#A1A1AA` | `#5E5E6B` | 占位、禁用 |
| `accent` | `oklch(0.58 0.19 268)` | `oklch(0.70 0.15 270)` | 强调（默认靛紫，跟随系统强调色可选） |
| `accentSoft` | accent @ 12% | accent @ 18% | 选中背景、标签激活 |
| `selection` | accent @ 22% | accent @ 32% | 文本选区 |
| `mark` | `#FFF1A8` | `#5C4B12` | `==高亮==` |
| `codeBg` | `#F5F5F7` | `#14141A` | 代码块 |
| `danger / warning / success` | `#E5484D / #F5A524 / #30A46C` | `#FF6369 / #FFB224 / #4CC38A` | 状态 |

高对比模式（`Preferences.HighContrast`）：`border`、`textMuted` 加深 / 提亮一级，焦点环不透明。

### 4.2 字体与排版
| 层级 | 字号（基于正文 16） | 字重 | 其他 |
|---|---|---|---|
| H1 | 2.0 em | 700 | 字距 −0.02 em，上 1.6 em / 下 0.6 em |
| H2 | 1.5 em | 650 | 上 1.4 em / 下 0.5 em |
| H3 | 1.25 em | 600 | |
| H4–H6 | 1.1 / 1.0 / 0.95 em | 600 | H6 用 `textMuted` |
| 正文 | 16（设置 13–24） | 400 | 行高 1.75（CJK 友好），段距 0.75 em |
| 代码 | 0.9 em | 400 | JetBrains Mono → Cascadia Code / SF Mono / DejaVu Sans Mono |
| UI | 13（侧栏/标签）/ 12（状态）/ 11（徽标） | 400–600 | 系统字体：SF Pro / Segoe UI Variable / Cantarell |

正文字体默认系统无衬线 + CJK 回退（PingFang SC / Microsoft YaHei UI / Noto Sans CJK SC），可在设置中改为衬线（思源宋体/系统 Serif）。

### 4.3 间距、圆角、阴影
- 间距：4 DIP 网格（`theme.Spacing = 4`），常用 4/8/12/16/24/32/48/72。
- 圆角：控件 6、卡片/弹层 10、命令面板 14、胶囊 999。
- 阴影（弹层）：`0 8 24 0 rgba(0,0,0,.12)` + 内描边 hairline（深色 `rgba(255,255,255,.06)`）。

### 4.4 动效令牌（`internal/views/motion`）
| 令牌 | 定义 | 用途 |
|---|---|---|
| `Quick` | 曲线 120 ms EaseOut | 悬停颜色、标记淡入淡出 |
| `Snappy` | Spring 260 ms, bounce 0.15 | 按钮、胶囊、弹层出现 |
| `Smooth` | Spring 360 ms, bounce 0 | 布局变化、侧栏、滚动 |
| `Gentle` | Spring 520 ms, bounce 0.1 | 大面板、Shared Element 飞行 |
| `Stagger` | 每项 +24 ms，上限 8 项 | 列表/面板逐项进入 |

规则：所有动画可打断（Spring 保持速度）；`ReduceMotion` 下位移/缩放取消、颜色与淡入保留；优先使用 `AnimatePose`/`ContentTransition`（仅重绘），避免每帧重建大视图。

## 5. 关键交互规范

### 5.1 光标处显隐（Reveal）
- 默认 **内联级**：光标位于某内联节点内部或紧邻其边界时，该节点及其祖先节点的标记以 `textMuted` 显示（`Quick` 淡入，宽度变化不做动画以免文字抖动）；离开后隐藏。
- 标题 `#`：光标在标题块内时显示于行首（淡色）。
- 代码块围栏、数学块 `$$`、Front Matter `---`：光标进入块时显示。
- 列表符号、引用 `>`：始终渲染为装饰，不显示为文本；行首 Backspace 执行"降级/移除列表"命令而不是逐字删除隐藏字符。
- 选区跨越节点时：选区内节点全部显示标记（避免"复制了看不见的东西"的困惑）。
- 设置项：`显隐粒度 = 内联 | 块 | 始终显示源码标记`。

### 5.2 软换行
- 默认 `换行显示`：源码中段落内单个换行显示为换行（与源码结构一致，避免硬换行文档重排）。
- 可选 `空格显示`（CommonMark 语义）。

### 5.3 斜杠菜单（P1）
- 空段落或行首输入 `/` → 光标下方弹出玻璃菜单（`Snappy` scale 0.96→1 + 淡入），模糊过滤；↑↓ 选择，Enter 插入，Esc 关闭并保留 `/`。
- 项：标题 1–3、无序/有序/任务列表、引用、代码块（再选语言）、表格（再选尺寸网格）、数学块、Mermaid、图片、分隔线、目录、脚注。

### 5.4 命令面板 / 快速打开
- `Ctrl/⌘+P`：文件模式；`Ctrl/⌘+Shift+P`：命令模式（输入框带 `>`）；`@` 前缀跳转标题。
- 外观：窗口上方 1/5 处居中，宽 640，玻璃面板（GPU）/ `surface` 98%（CPU）；背景压暗 8%；边框极淡的流光（`BorderConicGradient` + `Loop`，`ReduceMotion` 关闭）。
- 每项：图标、标题（匹配字符高亮）、右侧快捷键 KeyHint 胶囊；分组标题（最近 / 命令 / 文件）。
- 打开文件时：选中行的文件名与标签栏新标签共享 `Match`，飞入标签栏（`Gentle`）。

### 5.5 保存状态
- 胶囊圆点：编辑中（`textFaint` 空心）→ 保存中（`accent` 脉动 `Loop`）→ 已保存（圆点 `ContentTransition` 变为对勾，1.5 s 后淡回圆点）。
- 冲突：顶部横幅"文件已被其他程序修改"：`保留我的版本` / `载入磁盘版本` / `对比`（P2）。

### 5.6 文件树
- 展开/折叠：箭头旋转（`AnimatePose` Rotate），子项 `Collapse` 进入。
- 拖拽移动：拖动时行轻微上浮（`Pose{Scale:1.02, Y:-2}`），目标文件夹高亮；落下后新位置行 `Smooth` 过渡。
- 行内重命名：F2 / 双击名称；冲突名即时红色提示。

### 5.7 大纲
- 滚动联动：当前标题左侧指示条以 `Transition{Position}` 滑动（scroll spy）。
- 点击：`ScrollTo(…, Smooth)`，到达后目标标题背景 `AnimateColor` 闪烁一次。

### 5.8 表格
- 悬停表格出现行/列手柄（玻璃小胶囊）；右键菜单：上/下插入行、左/右插入列、删除、对齐、格式化表格。
- Tab / Shift+Tab 跨单元格；最后单元格 Tab 新增一行；`Ctrl/⌘+Enter` 下方插入行。

### 5.9 数学与 Mermaid（P1）
- 未激活：渲染结果（公式基线对齐，块级居中）。
- 激活：显示源码（等宽、`surface` 背景）+ 下方实时预览卡片（渲染失败显示错误信息，红色细边）。

### 5.10 模式切换
- 源码模式：内容交叉淡化（`Quick`），保持光标所在行在视口中的相对位置。
- 阅读模式：侧栏与标题栏淡出（`Smooth`），顶部 2 DIP 阅读进度条随滚动；文档 H1 滚出视口后，其文字以小号淡入标题栏中央（Craft/Apple 式）。
- 专注模式：非当前块 `Opacity 0.35`（`AnimatePose Fade`，仅重绘）。
- 打字机模式：光标行保持在视口 45% 高度（`ScrollTo Smooth`）。

## 6. 材质与 Shader 使用规范

| 位置 | GPU 路径 | CPU / 减少透明度 |
|---|---|---|
| 标题栏 + 侧栏 | macOS / Win11：窗口 Vibrancy（侧栏）+ `glass.ScrollEdge{Soft}`（内容滚入标题栏下方） | `chrome` 纯色 |
| 命令面板、斜杠菜单、格式条、状态胶囊、链接弹层 | `glass.Glass{Regular}`，按钮 `Interactive: true` | `surface` 98% + 阴影 |
| 图片灯箱控件 | `glass.Glass{Clear}` | 半透明黑 60% |
| 欢迎页背景 | 自定义极光 Fragment Shader（低频噪声 + 强调色），空闲 3 s 后停止请求帧 | 静态渐变 |
| 主题切换 | LayerEffect 自点击点径向溶解过渡 400 ms | 交叉淡化 |
| 加载占位 | 线性渐变扫光（`Loop`） | 静态 |

硬性约束：Shader 仅用于装饰，不承载信息；全部 `p.Accelerated()` 门控；`ReduceMotion` 下关闭位移类效果；常驻视图中不得有持续请求帧的动画（空闲必须 0 帧）。

> 冲突说明：`Ctrl+1…6` 为标题（Typora 习惯）；标签切换使用 `Ctrl+Tab` 与 `Alt+1…9`（Windows/Linux）/ `⌘+Option+1…9`（macOS）。快捷键表由 `core/commands` 维护并做冲突检测。

## 8. 无障碍与国际化
- 编辑器角色为多行文本框，带标签；所有命令可键盘到达；焦点环可见；`TextScale`、高对比、减少动态效果、减少透明度均遵循。
- 已知限制：读屏软件读取全文能力弱于系统文本控件（自定义编辑器只向辅助技术暴露活动区域）。
- 界面语言：简体中文、英文（P1）；文案键按模块分片（见 05 文档 §3.4）。
