# ADR-001 编辑引擎

状态：已决定（S1 Go）。

**决定：** 用自定义元素 + `TextInputClient` 自研编辑引擎，不启用“块级源码切换”后备。

**依据 [实测]：** 1 万块滚动每帧通常重排 1–3 块；≤ 200 KB 击键合计约 4.1 ms；50 个 Tester 回归测试通过。微软拼音由用户在 Windows 真机检查通过。

**风险：**
- macOS、Linux 的 IME 未验证。
- `RevealInline` 是最大的遗留风险，FE-1.1 要覆盖。
- S1 有一次首帧 1915 ms，只出现一次，原因未证实。冷启动预算要在 FE-1.1 后单独测。
