# ADR-002 公式与图表渲染

状态：**建议方案，等用户确认。**

**背景：** S2 按原标准 No-Go [实测]：
- 47/50 公式视觉完整（94% < 95%）。3 个中文用例输出 `<text>`，MyGo 不绘制。
- 未缓存 p95 48.2 ms，但 2/50 次超过 50 ms，最大 161 ms。
- 缓存和 1000 次连续 `Eval` 都通过。Mermaid 六种图可导出 PNG。
- WebView2 进程树工作集 361–565 MiB，规划预估是 80–150 MB。这是工作集总和，不等于独占物理内存。

**建议：**
1. 保留离屏 WebView 服务。公式能转矢量的用 SVG；含 `<text>` 的用 PNG（CR-005，已写入契约）。
2. 渲染失败或服务不可用时显示公式源码，不显示残缺结果。
3. 服务懒启动：文档没有公式和图表时不启动。空闲一段时间后退出。
4. 单公式预算改为 p95 < 50 ms。冷渲染的长尾由异步显示承担，不阻塞击键。

**备选：**
- 只显示源码 + 外部浏览器预览：最省内存，但实时模式看不到公式。
- 中文转路径：保持矢量，要额外的字体轮廓和排版工作，未实现。
- 纯 Go TeX 子集：覆盖度未测，上游已迁移仓库。

**未验证：** PNG 路径的端到端耗时、2× 缩放和基线对齐；服务退出后重启的耗时；空闲退出能回收多少内存。BE-2.1 要实测这些，结果不达标时退回“只显示源码”。
