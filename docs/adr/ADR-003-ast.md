# ADR-003 AST 适配

状态：已决定（用户确认 2026-11-01）。

**背景：** S3 的严格前缀标准 No-Go [实测]：删除前缀后等于 `parser.Lines` 的叶子块 1,925/1,934，差异来自部分 Tab 的剩余空格。段落和标题 1,531/1,531 通过。

**决定：**
1. 把标准改为逐行映射（`Block.Lines`，CR-003，已写入契约），该映射 1,934/1,934 通过。
2. BlockID 只承诺“未被语法吞并的存活块保持 ID”（CR-004）。三个种子共 30,000 步，1,085,936 次检查通过。
3. 覆盖规则用 `Lead`、`Trailer`、`BlockBlank`、`BlockLinkDef`（CR-001）。语料和 30,000 步随机编辑都无缝无叠。
4. 不直接依赖 `parser.Edit`：已有代码块合并、引用和脚注缓存失效的反例，保留两项保守回退。MyGo 版本锁定在 v0.7.3，升级时要重跑。
5. 5 MB 文档默认走大文件模式。

**实现要处理：**
- 原型每次重建全文，不能用于击键路径。不可变多版本快照、Dirty 传播、投影缓存都还没做。
- 有 2 种情形文本会落进隐藏的 `Lead`/`Trailer`：引用里只有链接定义、表格行多余的单元格。字节不丢，但实时模式看不到，BE-1 要处理。
